# Changelog

All notable changes to this plugin. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-22

### Added
- First release: the SecuLynx diagnostic in Claude. Passive scan of your
  domain after email verification, six business scenarios, management and
  technical PDF reports.
- Claude Code plugin with marketplace, MCP connector and the `diagnostic` skill.
- Skill zip for Claude.ai and Claude Desktop.
- Contribution guide, security policy, pull request template.
- Continuous validation of the plugin on every push and pull request.
- Automated GitHub releases with the Claude.ai skill zip, from version tags.
